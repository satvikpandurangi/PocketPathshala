# Android and hotspot setup

## Laptop demo first

Node ≥22.13, pnpm install, pnpm build, pnpm demo:seed, pnpm dev. Hub binds 0.0.0.0:8080 and prints local interface URLs. Use localhost for browser offline service workers. Plain HTTP on another phone can access the hub but cannot install a secure-context browser service worker; the packaged Capacitor app is the offline phone path.

## Capacitor build (requires Android SDK/JDK)

The native project is already generated. Debug compilation succeeded with Java 21, SDK 36 and min SDK 28. No phone is connected; installation/runtime checks remain pending. Skip android:add for this checkout. APK contains local shell, fonts and the text/SVG pack; no audio is claimed.

From apps/app run pnpm android:add once, pnpm android:sync after each web build. capacitor.config.ts uses appId org.klarity.pocketpathshala, webDir dist, Android HTTP scheme and native CapacitorHttp. Cleartext is allowed only for classroom LAN prototype operation. Audit AndroidManifest and network security config before installing. In android run .\gradlew.bat assembleDebug on Windows, ./gradlew assembleDebug on Linux. Debug APK uses Gradle’s generated debug key; never invent a release signing key. APK output is app/build/outputs/apk/debug/app-debug.apk. No APK exists until this command succeeds.

## Teacher Termux

Install maintained Termux from its official distribution. Run pkg update then pkg install nodejs. Verify node --version ≥22.13 and node:sqlite import. Transfer dist/termux/ generated by pnpm hub:bundle. Run cd into that directory, then DEMO=1 node hub.mjs. Keep Termux foreground or acquire a wake lock and exempt it from battery optimization. Phone hotspot ON; mobile data OFF; students join teacher hotspot. Enter the teacher LAN address printed by the hub. Gateway 192.168.43.1 is only a common hint, never a guaranteed address. QR presents a URL; scanning in-app remains deferred.

| Failure                      | Check / recovery                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- |
| Hub unreachable              | Same hotspot; printed interface IP; port 8080 firewall; hotspot client isolation; avoid cellular address |
| IP changes                   | Re-enter address; reconnect pack is still local                                                          |
| Cleartext error              | Re-sync native project; inspect Capacitor scheme/native HTTP and manifest settings                       |
| Hub stops screen-off         | Termux wake lock, battery exemption; rehearse at least ten minutes                                       |
| node:sqlite missing          | Upgrade Node/Termux; fallback laptop hub, disclose fallback                                              |
| Browser offline reload fails | Use localhost or install Capacitor APK; plain LAN HTTP has no service-worker guarantee                   |
| Kannada squares/audio silent | Verify font glyph support, reviewed recordings, volume; show text and missing-audio label                |

Do not assert Android/hotspot completion from configuration alone. Two physical phones, mobile data disabled, app reload and return sync are the acceptance test.
