# Vision

Pocket Pathshala is Team Klarity's wHACKiest 2026 UnlockED Track 4, Problem Statement 2 entry. Satvik Pandurangi and Samarth G Ichageri, Jain College of Engineering and Technology, Hubballi, are building offline adaptive practice for rural multi-grade classrooms. The online demonstration is November 26–27, 2026 IST; the on-campus extension is December 1–2.

Meena, Class 4, shares a family Android phone and prefers Kannada. Her answer 52 − 27 = 35 is a useful diagnosis, not just a failure. Ravi sir teaches 38 children across Classes 1–5 with patchy 2G. He needs skill groups he can act on immediately. A cluster coordinator across five schools is a later audience.

Success means a child can select a private learning profile, practise from a saved pack with no internet, receive a targeted hint, and deliver progress to a teacher over LAN. Children in different grades with the same gap appear together. Cloud transfer is optional and small. Under 5 MB/student/month is a target requiring measurement, not an established impact result.

Non-goals for the first demo: video, runtime generative AI, account systems, high-stakes assessment, real pilot impact claims, production cloud deployment. Device ownership is shared; learning identity is not. See 12-pitch-alignment.md for live feature status.
